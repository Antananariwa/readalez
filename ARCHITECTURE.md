# Architecture

The code's stable shape, in the form of [matklad's ARCHITECTURE.md](https://matklad.github.io/2021/02/06/ARCHITECTURE.md.html): a bird's eye view, a code map that names the important files and types, and the invariants. It leaves out how each part works. Significant technical decisions: [docs/adr](docs/adr/).

## Bird's eye view

What the app does: [SPEC.md](SPEC.md). In the code, `src/core/` turns a book's text into words with their durations, as plain TypeScript (ADR 0003). `src/ui/` plays them with React and keeps the library in the browser's storage, in a PWA (ADR 0002).

## Code map

### `src/core/`

The reading logic, with its unit tests beside it (`*.test.ts`) and their texts in `fixtures/`. `epub/testZip.ts` builds ZIP files for the tests and for `scripts/build-books.ts`; the app doesn't use it.

- **Words:** `text.ts` splits a book's sections (`Section`) into the words the reader shows (`Word`, `splitText`). It uses `words.ts` for word boundaries, `longWords.ts` for chunks and `focus.ts` for focus letters.
- **Timing:** `timingValues.ts` holds the timing values and the speed range. `durations.ts` gives each word its duration (`Timing`), and `sentences.ts` finds sentence ends and starts. `schedule.ts` plays the words on a fixed schedule from frame times the caller passes in. `timeLeft.ts` works out time left.
- **Reading flow and chapters:** `readingFlow.ts` holds the reading flow over the words and its parts (`Part`, ADR 0011): where it starts, which word plays next and where chapters start. `chapterText.ts` gives the paused view a chapter's paragraphs and where each word sits in them.
- **Adding books:** `paste.ts` reads pasted text (`parsePaste`). `epub.ts` reads an EPUB file into sections and a chapter list (`parseEpub`, `Chapter`, ADR 0009) with the readers in `epub/`: `zip.ts` for the archive, `xml.ts` for XML documents, `package.ts` for the package document, `toc.ts` for the table of contents, `content.ts` for the XHTML documents, `flow.ts` for the parts, and `encryption.ts` for copy-protected files.
- **Library and positions:** `library.ts` holds what the library knows about a book (`BookInfo`). `bookId.ts` names a book by the SHA-256 of its words (ADR 0007). `position.ts` holds a position (`Position`), finds it again after the splitting rules change, and works out the progress and time left saved with it (ADR 0008). `builtInBooks.ts` is the built-in books' catalog, generated by `npm run books` (ADR 0013).
- `webApis.d.ts` declares the web APIs core may use (ADR 0009).

### `src/ui/`

React components and everything that touches the browser. `main.tsx` starts the app.

- **Screens:** `App.tsx` switches between the library (`Library.tsx`), the Add text screen (`AddText.tsx`) and the reader (`Reader.tsx`), in React state with no router.
- **Reader:** `Reader.tsx` holds the reader's controls, the progress bar (`ProgressBar.tsx`), time left and the chapter list (`ChapterList.tsx`). `WordFrame.tsx` draws the word frame, `PausedText.tsx` the paused view and `FinishedCard.tsx` the Finished card. `usePlayback.ts` runs the `requestAnimationFrame` loop that drives `schedule.ts`. `useWakeLock.ts` keeps the screen on while words play (SPEC.md feature 7).
- **Storage and import:** `storage.ts` keeps the library in IndexedDB (ADR 0007), positions included (ADR 0008). `useSavePosition.ts` saves the position while reading (SPEC.md feature 4). `importEpub.ts` reads an EPUB file with progress (`readEpub`), for an import and for a built-in book's first open (ADR 0013).
- **Offline:** `registerServiceWorker.ts` registers the service worker that `vite-plugin-pwa` builds from `vite.config.ts` (ADR 0006). `useOfflineBooks.ts` counts the built-in books the service worker has saved.
- `styles.css` holds the layout, including where the focus point sits, and the light and dark themes.

### Other folders

- `public/`: files served as they are. The app icons are rendered from `icon.svg` (`npm run icons`). `books/` holds the built-in books' EPUB files.
- `scripts/`: Node scripts. `build-books.ts` and `builtInBook.ts` build the built-in books and their catalog (`npm run books`, ADR 0013). `review-log.ts` and `append-review.ts` add a merged PR's review to `docs/reviews.md`, run by `.github/workflows/reviews.yml`. `render-icons.ts` renders the app icons (`npm run icons`).
- `e2e/`: Playwright tests against the production build, one spec file per area, with shared helpers in `helpers.ts` (ADR 0005, ADR 0010).
- `tests/`: unit tests that read files, which tests in `src/core/` can't (ADR 0009), and the scripts' tests. `builtInBooks.test.ts` checks the built-in books against their catalog. `epub/` checks the test books in `fixtures/epub/`, which its README lists. `tooling/` checks the Playwright version pin, `scripts/review-log.ts`, and that the app's code never sends the service worker `SKIP_WAITING` (SPEC.md feature 12).

## Invariants

- `src/core/` imports nothing from `src/ui/` or React. It uses no browser or Node globals apart from those declared in `src/core/webApis.d.ts` (ADR 0003, ADR 0009).
  Enforced by `npm run check`, through `tsconfig.core.json` and `.oxlintrc.json` (ADR 0005).
- `src/ui/` holds no reading logic.
