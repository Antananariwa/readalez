# Architecture

The stable shape of the code. Reasons for the big choices: docs/adr/.

## Bird's eye view

A text is split into words and timed. The UI shows the words one at a time with a focus point.

## Code map

- `src/core/`: the reading logic in plain TypeScript: splitting text, focus position, timing, parsing imported texts.
  `text.ts` turns sections and paragraphs into the words the reader shows (`splitText`, or `splitTextInSteps` to show progress between steps), using `words.ts` for word boundaries, `longWords.ts` for splitting words over 13 letters and `focus.ts` for focus letters.
  `timingValues.ts` holds the timing values and the speed range; `sentences.ts` finds sentence ends (abbreviations included) and sentence starts; `durations.ts` gives each word its duration; `schedule.ts` plays the words on a fixed schedule from frame times the caller passes in, with no timers; `timeLeft.ts` sums the remaining durations for the chapter and the reading flow, and `timeLeftTable` works them out once per speed for lookups at each word.
  `chapterText.ts` gives the paused view each paragraph as written and where each word sits in it (`chapterTexts`), a chapter's paragraphs across sections (`chapterText`), turns a character of a paragraph into a word (`wordAtCharacter`) and counts the words for the Finished card (`wordCount`).
  `paste.ts` reads pasted text (`parsePaste`): it keeps only the part between Gutenberg's markers, splits paragraphs at blank lines, joins hard-wrapped lines (`isHardWrapped`) or else makes each line a paragraph, and takes the title from the first line, as one section.
  `epub.ts` reads an EPUB file (`parseEpub`, ADR 0009): its title, author, one section per spine item, then a section of notes, the chapter list (`Chapter`) and the reading flow's parts (ADR 0011). It refuses a copy-protected book (`DrmError`), whose locked files `epub/encryption.ts` reads from `META-INF/encryption.xml`. It uses the readers in `epub/`: `zip.ts` for the archive, which checks each file against its CRC-32, `xml.ts` for its XML documents, `package.ts` for the package document's metadata, spine and EPUB 2 guide, `toc.ts` for the table of contents, `content.ts`, which turns an XHTML document into paragraphs, keeps notes apart, drops note markers and marks each paragraph's role, and `flow.ts`, which finds the parts (`findParts`).
  `readingFlow.ts` holds the reading flow over the words (`readingFlow`, ADR 0011): where it starts, what plays next (`nextWord`), progress over it, the sentence starts a move can reach, and where chapters start (`chapterBounds`). `epub/testZip.ts` builds small EPUBs for the tests, and zips the built-in books (`zipArchive`). `webApis.d.ts` declares the web APIs core may use.
  `bookId.ts` names a book by the SHA-256 of its words (`bookId`, ADR 0007); `library.ts` holds what the library knows about a book (`BookInfo`), the built-in books it lists before they're stored (`libraryBooks`), where a book comes from for the library's chips (`bookSource`) and its order (`libraryOrder`). `builtInBooks.ts` is the built-in books' catalog (`BuiltInBook`), generated by `scripts/build-books.ts` (ADR 0013). `position.ts` holds a saved reading position (`Position`), finds it again after the splitting rules change (`findPosition`), and works out the progress and time left stored with it (`readingState`, `bookTimeLeft`, ADR 0008).
- `src/ui/`: React components and everything that touches the browser. It asks `src/core/` what to show and when.
  `App.tsx` switches between the library (`Library.tsx`, the home screen, with the All, Free shelf and My books chips and the rename and delete dialog), the Add text screen (`AddText.tsx`, with Import EPUB and its progress bar, the dialog for a book already in the library, and the paste box) and the reader (`Reader.tsx`) in React state, with no router. `useOfflineBooks.ts` counts the built-in books the service worker has saved, for the library's offline band. `importEpub.ts` reads an EPUB with progress (`readEpub`), for Import EPUB and for a built-in book's first open, which `App.tsx` fetches from `public/books` (ADR 0013). `storage.ts` keeps the library in IndexedDB (ADR 0007), reading positions included (ADR 0008). `App.tsx` opens a book at its saved position, or where its reading flow starts, sends a newly imported book to the library and keeps which one to mark New in React state only, and `useSavePosition.ts` saves the reader's position at the moments SPEC.md feature 4 lists. `WordFrame.tsx` draws the word frame: CSS in `styles.css` centres the focus letter on a fixed point 40% of the way across, and a word too wide for the frame is measured and shrunk. `Reader.tsx` adds the buttons under the frame (`RepeatButton.tsx` for the speed buttons, which keep stepping while held), the desktop keys, pausing when the page is hidden, the progress bar over the reading flow (`ProgressBar.tsx`), time left, and the chapter list (`ChapterList.tsx`, a dialog). When paused it shows the chapter's text (`PausedText.tsx`, one text node per paragraph, with a tap turned into a place in the text by the browser's caret-from-point API); after the last word it shows the Finished card (`FinishedCard.tsx`). `usePlayback.ts` runs the `requestAnimationFrame` loop, asks `schedule.ts` which word to show (and `readingFlow.ts` which follows) and `sentences.ts` where to jump and where the progress bar lands, and holds the speed and whether reading has finished. `useWakeLock.ts` keeps the screen on while words play. `styles.css` holds the light and dark themes, which follow the system.
  `src/ui/registerServiceWorker.ts` registers the service worker that `vite-plugin-pwa` builds from `vite.config.ts`, which also writes the web app manifest (ADR 0006).
- `public/`: files served as they are, including the app icons. `npm run icons` renders the PNGs from `public/icon.svg` with `scripts/render-icons.ts`. `public/books/` holds the built-in books' EPUBs, which `npm run books` builds from Standard Ebooks' repositories with `scripts/build-books.ts` and `scripts/builtInBook.ts`, along with their catalog in `src/core/builtInBooks.ts` (ADR 0013).

## Invariants

- `src/core/` never imports from `src/ui/`, React or browser APIs (ADR 0003). The only web APIs it uses are the ones Node also has, each declared in `src/core/webApis.d.ts` (ADR 0009).
  Enforced by `npm run check`, through `tsconfig.core.json` and `.oxlintrc.json` (ADR 0005).
- `src/ui/` holds no reading logic.
